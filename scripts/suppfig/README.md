# Supplementary figure scripts

This directory contains scripts and notes used to generate Supplementary Figures 1–4.

## Directory structure

- `01_suppfig1_2_model_and_odor_semantic/`: supplementary model-validation and odor-semantic analyses for Supplementary Figures 1–2.
- `02_suppfig3_4_transcriptome_voc_support/`: supportive leaf–peel transcriptome/VOC analyses for Supplementary Figures 3–4.

The former exploratory public held-out odor-model scripts are not included in this supplementary-figure directory because they are not used to generate the submitted Supplementary Figures.

Processed support tables are archived in the Zenodo data repository under `processed/figure_support/`, with Supplementary Figure support files named using the `suppfigX_*` prefix.
